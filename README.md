# 尤利西斯 · 中文重译与夹注

逐章重译詹姆斯·乔伊斯的 *Ulysses*，制作适合连续阅读的中文本，以及便于细读原文的中英对照本。

以“信、达、雅”为方向；直译更能保留原作的声音时，就保留直译。对双关、典故、文化差异和难以兼顾的语义，采用接近《红楼梦》脂评的简短夹注，尽量让解释贴近阅读发生的地方。

**18 章译稿、夹注及中文、中英对照 PDF 现已齐备；第 1–3 章另有选择性旁注导读版。** 本项目使用 AI 辅助翻译、核典与排版，译稿持续校订，欢迎依据原文提出修正。

第 15、18 章涉及明确未成年人物的少量露骨性细节，在出版稿中作非露骨概述，中英文均以编者标记明示，范围记入各章校译记录。这两章不作为无删节译本；原始底本文件保持不动。

## 翻译与排版

- 保留底本的部、章编号和叙述层次，不把通行的荷马对应名称增作原文章题。
- 尽量保留人物口吻、意识流、重复意象和有意悬空的主语；不把解释补进正文。
- 对承接、回应或回响起作用的重复词句，保持可辨认的共同译语，连同跨章复现一并核对；确有词义变化或双关时保留差异，必要时简注说明。
- 夹注从简，说明难以兼顾的音义、文化背景与必要出处；有解释性质的判断应与事实区分。
- 中文正文为 10.5 磅宋体，夹注为 8 磅淡红色宋体，不显示“注：”及方括号。
- 对照本原文为 9.5 磅浅灰蓝色 Georgia（`#929CA6`），保留斜体与诗行；降低原文的视觉分量，方便连续阅读中文时跳过。
- 旁注导读本为 240 × 240 毫米，保持原对照栏的行宽，右栏采用 9 磅灰绿色宋体（`#466D68`）；每条旁注与相应中英文阅读单元同页、顶端对齐。

各章现稿夹注数量依次为：63、34、82、29、27、31、56、36、52、39、18、38、20、22、56、37、41、15 条。译名、取舍及已核对的参考资料见各章校译记录；跨章沿用的原则见 [AGENTS.md](AGENTS.md)，包括保留歧义、区分人物声音、保留句法节奏、兼顾双关与典故、保留人物错记，以及区分注释中的事实与解释。

## 本地重建

直接阅读 PDF 无须安装依赖。重建需要 Python 3.10 或更新版本，以及具有相应使用和嵌入许可的字体。

```sh
python -m pip install -r requirements.txt
python scripts/split_chapters.py
python scripts/build_chapter_pdf.py 01
python scripts/build_chapter_pdf.py 02

python scripts/build_chapter_pdf.py 04
python scripts/build_chapter_pdf.py 05
python scripts/build_chapter_pdf.py 06
python scripts/build_chapter_pdf.py 07
python scripts/build_chapter_pdf.py 08
python scripts/build_chapter_pdf.py 09
python scripts/build_chapter_pdf.py 10
python scripts/build_chapter_pdf.py 11
python scripts/build_chapter_pdf.py 12
python scripts/build_chapter_pdf.py 13
python scripts/build_chapter_pdf.py 14
python scripts/build_chapter_pdf.py 15
python scripts/build_chapter_pdf.py 16
python scripts/build_chapter_pdf.py 17
python scripts/build_chapter_pdf.py 18
```

分章脚本核对完整底本的字节与校验和；已有分章文件被改动时会拒绝覆盖。排版脚本读取该章原文及译稿，输出 PDF，不改动输入文本。目前 `01`–`18` 全部完成检查，共 39 份 PDF（18 份中文本、18 份对照本、3 份导读本）。

默认同时生成两版，也可单独生成：

```sh
python scripts/build_chapter_pdf.py 01 --edition zh
python scripts/build_chapter_pdf.py 01 --edition parallel
python scripts/build_chapter_pdf.py 03 --edition commented
```

旁注版需要该章的 `side-comments.json`（格式版本 2），目前第 1–3 章已备齐。段号按原文空行分段计数，含部、章标记，但标题不配旁注；无须解释的段落不列入文件。长段数组按 `parallel-segments.json` 的切分次序排列，不加注的切分用 `null` 占位，避免后续旁注错位。原文、译稿或切分文件改变后，须逐条复核旁注并更新输入校验和；排版脚本校验段号、切分数量、内容格式和校验和，允许有意留白。

可选的 `layout.json` 用 `heading_paragraphs` 记录章内标题段号，用 `verse_group_break_before` 区分相邻但独立的诗节。报纸标题、星号分节标记与后续正文保持同页；`keep_with_next_paragraphs` 可将指定问句与首答相连，`zh_keep_together_paragraphs` 可让指定中文段落整段同页。`accounting_paragraphs` 将指定账表的金额右对齐；保留硬换行的段落只允许在中英完整行末作已核对切分。这些配置只控制排版，不改变译稿段界。

第 15、18 章的 `source-overrides.json` 保存有限编者处理的出版英文段落及原段校验和；中文 `【编者概述：…】` 与英文 `[Editorial omission: ...]` 均在 PDF 可见。构建、切分与验证采用相同的出版文本，不修改 `original.txt`。每次处理范围的变更须同步核对译稿、切分及校译记录。

运行 `python scripts/verify_chapter_pdf.py 01` 可核对该章现有各版的正文、夹注、英文、旁注、字体嵌入、页界和对读同页关系；`--edition commented` 可只核查导读版。仍须另行逐段语义校读并渲染检查版面。

Windows 默认使用 `C:/Windows/Fonts/simsun.ttc`、`georgia.ttf` 和 `georgiai.ttf`。其他路径可通过参数指定：

```sh
python scripts/build_chapter_pdf.py 01 --font "/path/to/simsun.ttc" --english-font "/path/to/georgia.ttf" --english-italic-font "/path/to/georgiai.ttf"
```

也可设置 `ULYSSES_SONG_FONT`、`ULYSSES_ENGLISH_FONT` 和 `ULYSSES_ENGLISH_ITALIC_FONT`。第 16 章的主教署名十字符号 ✠ 单独使用嵌入的 Segoe UI Symbol，保留原字符与所在正文的字号、颜色；默认路径为 `C:/Windows/Fonts/seguisym.ttf`，可用 `--symbol-font` 或 `ULYSSES_SYMBOL_FONT` 指定。第 18 章错拼中的组合删除斜线采用 Times New Roman，默认 `C:/Windows/Fonts/times.ttf`，可用 `--mark-font` 或 `ULYSSES_MARK_FONT` 指定。仓库不分发独立字体文件；替换字体会影响换行和页数。生成后应检查文字完整性，并渲染逐页校样。

## 参与校订

欢迎通过 Issue 或 Pull Request 提出改译、补充可靠出处，或报告排版问题。请给出章节、原句、当前译文，以及建议和理由；核典尽量链接到原作、学术机构或可复核的文献。

修改译稿时保留与 `original.txt` 一致的空行分段，诗行缩进四个空格。`【注：……】` 仅是译稿的内部标记，PDF 会将其转为小号淡红夹注。若改动涉及对照本的长段切分，请同步更新 `parallel-segments.json`，重建相关版本并核对页面；已有旁注的章节还须复核 `side-comments.json`。旁注的取舍、语气和排版遵循 [AGENTS.md 的旁注原则](AGENTS.md#side-comment-principles)。提交到相应目录的新增内容沿用该目录的许可证。
